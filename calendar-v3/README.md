# Calendar V3 - Blank Template

A clean, minimal calendar template ready for customization.

## Features

- **Clean Design**: Minimal, modern interface with a purple gradient theme
- **Responsive Layout**: Works on desktop and mobile devices
- **Basic Functionality**: Month, week, and day views
- **Event Management**: Add, view, and manage events
- **Local Storage**: Events are saved locally in the browser
- **Modal System**: Clean modal dialogs for adding and viewing events

## File Structure

```
calendar-v3/
├── index.html          # Main HTML structure
├── styles.css          # Clean, minimal CSS styling
├── script.js           # Basic calendar functionality
└── README.md           # This file
```

## Usage

1. Open `index.html` in your web browser
2. Navigate through months using the arrow buttons
3. Click "Today" to return to the current date
4. Switch between Month, Week, and Day views
5. Click on any day to add a new event
6. Click on existing events to view details

## Customization

This blank template is ready for customization:

- **Colors**: Modify the CSS color variables in `styles.css`
- **Layout**: Adjust grid layouts and spacing
- **Features**: Add new functionality in `script.js`
- **Content**: Modify the HTML structure in `index.html`

## Technical Details

- **Vanilla JavaScript**: No external dependencies
- **CSS Grid**: Modern layout system for the calendar
- **Local Storage**: Events persist between browser sessions
- **Responsive Design**: Mobile-first approach with media queries

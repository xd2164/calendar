# 🚀 Quick Start - Deploy to Railway in 5 Minutes

## Prerequisites
- GitHub account
- This code pushed to a GitHub repository

## Steps

### 1. Push to GitHub
```bash
git add .
git commit -m "Add Railway backend"
git push origin main
```

### 2. Deploy to Railway
1. Go to https://railway.app
2. Click **"Login"** → Sign in with GitHub
3. Click **"New Project"**
4. Select **"Deploy from GitHub repo"**
5. Choose your repository (calendar-v16)
6. Railway will automatically:
   - Detect Node.js
   - Install dependencies
   - Deploy your app ✅

### 3. Add PostgreSQL Database
1. In your Railway project, click **"New"**
2. Select **"Database"** → **"PostgreSQL"**
3. Done! Railway automatically connects it ✅

### 4. Get Your Live URL
1. Click on your service (web)
2. Go to **"Settings"** tab
3. Scroll to **"Domains"**
4. Click **"Generate Domain"**
5. Your app is now live at: `https://calendar-v16-production.up.railway.app`

### 5. Test It!
Open your browser and go to your Railway URL. Your calendar should be live! 🎉

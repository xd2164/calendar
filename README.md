# Organizational Event Calendar

A comprehensive calendar application designed specifically for organizational event management, hyperscaler partnerships, joint themes, and collaboration activities. Built with modern web technologies to provide visibility into ongoing events and facilitate team collaboration.

## Features

### 🏢 Organizational Event Management
- **Hyperscaler Partnership Tracking**: Dedicated support for AWS, Azure, and GCP events
- **Joint Theme Assignment**: Collaborative themes with participant assignment
- **Collaboration Activities**: Ongoing activities for team discussion and coordination
- **Internal Events**: Standard organizational events and meetings

### 🎨 Modern Design
- Beautiful gradient backgrounds and smooth animations
- Responsive design that works on all devices
- Clean, intuitive user interface
- Color-coded event types with visual indicators

### 📅 Calendar Views
- **Month View**: Traditional monthly calendar layout
- **Week View**: Focused weekly view with enhanced event display
- **Day View**: Detailed single-day view for intensive planning
- Easy navigation between dates and views

### 🔍 Advanced Filtering
- Filter events by type (Hyperscaler, Joint Themes, Collaboration, Internal)
- Quick access to hyperscaler partnership statistics
- Real-time event counting and categorization

### ✨ Enhanced Event Management
- **Event Types**: Categorized events with specific workflows
- **Participant Assignment**: Assign team members to events and themes
- **Provider Selection**: Specific hyperscaler provider selection (AWS/Azure/GCP)
- **Discussion Threads**: Built-in collaboration and discussion for each event
- **Persistent Storage**: All data saved locally using localStorage

### 🚀 Interactive Features
- Click events to view details and participate in discussions
- Hover effects and smooth transitions
- Modal dialogs for event creation and management
- Today button for quick navigation
- Comprehensive sidebar with categorized event lists
- Real-time hyperscaler partnership statistics

## Getting Started

### Prerequisites
- Modern web browser (Chrome, Firefox, Safari, Edge)
- No additional dependencies required

### Installation

1. Clone or download the project files
2. Open `index.html` in your web browser
3. Start using the calendar immediately!

## Usage

### Basic Navigation
- Use the arrow buttons to navigate between months/weeks/days
- Click "Today" to return to the current date
- Switch between Month, Week, and Day views using the toggle buttons

### Managing Events

#### Adding Events
1. Click "Add Event" or "Add Hyperscaler Event" in the sidebar
2. Select the event type:
   - **Internal Event**: Standard organizational events
   - **Hyperscaler Partnership**: AWS, Azure, or GCP partnership events
   - **Joint Theme**: Collaborative themes for team assignment
   - **Collaboration Activity**: Ongoing activities for discussion
3. Fill in the event details:
   - **Title**: Event name
   - **Date**: When the event occurs
   - **Time**: Event time (optional)
   - **Description**: Additional details (optional)
   - **Participants/Assignees**: Team members involved
   - **Provider**: For hyperscaler events (AWS/Azure/GCP)
   - **Color**: Choose from predefined colors
4. Click "Save Event" to add it to your calendar

#### Viewing and Managing Events
- Events appear as colored dots with type indicators on calendar days
- Click on events to view details and participate in discussions
- Use the filter dropdown to view specific event types
- View hyperscaler partnership statistics in the sidebar
- See joint themes and collaboration activities in dedicated sections

#### Collaboration Features
- Click any event to open detailed view with discussion thread
- Add comments and participate in ongoing discussions
- Assign participants to joint themes and collaboration activities
- Track hyperscaler partnership activities with provider-specific indicators
